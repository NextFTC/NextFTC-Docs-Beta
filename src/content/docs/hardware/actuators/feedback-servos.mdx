`NextFeedbackServo` and `NextFeedbackCRServo` pair a [`NextServo`](/hardware/actuators/servos) or [`NextCRServo`](/hardware/actuators/cr-servos) with an analog feedback input, for servos with a feedback wire (e.g. Axon). They inherit everything from their base class and add `angle` for reading the servo's actual physical angle.

## Creating a feedback servo

Both classes pair the constructors you already know from [`NextServo`](/reference/servos) and [`NextCRServo`](/reference/cr-servos) with an already-constructed `AnalogFeedback` instance for reading the angle.
All of these below are interchangeable with `NextFeedbackCRServo`.

<Tabs syncKey="language">
<TabItem label="Kotlin">
```kotlin
// By configuration name
val armServo = NextFeedbackServo("armServo", NextAnalogInput("armEncoder"))

// By Lynx Module and port + NextAnalogInput
val armServo = NextFeedbackServo(RobotController.expansionHub, 0, NextAnalogInput("armEncoder"))

// Additionally, using a custom feedback method
val armServo = NextFeedbackServo("armServo", AnalogFeedback(voltageSupplier = { /* custom method here */ } ))
```
</TabItem>
<TabItem label="Java">
```java
// By configuration name
NextFeedbackServo armServo = new NextFeedbackServo("armServo", new NextAnalogInput("armEncoder"));

// By Lynx Module and port
NextFeedbackServo armServo = new NextFeedbackServo(RobotController.getExpansionHub(), 0, new NextAnalogInput("armEncoder"));

// Additionally, using a custom feedback method
NextFeedbackServo armServo = new NextFeedbackServo("armServo", new AnalogFeedback(/* tbd, idk java*/))
```
</TabItem>
</Tabs>

The servo port must be in the range `[0, 5]`. Both constructors also accept the same optional `cacheTolerance` parameter as their base class.

## Usage

### `angle`

The servo's actual physical angle, read from the analog feedback input and returned as a typed `Angle`.

<Tabs syncKey="language">
<TabItem label="Kotlin">
```kotlin
val currentAngle = armServo.angle
```
</TabItem>
<TabItem label="Java">
```java
Angle currentAngle = armServo.getAngle();
```
</TabItem>
</Tabs>
